# Sia Motors — новый сайт (демо)

Варианты нового одностраничного сайта siamotors.ru: привоз автомобилей из Китая, Кореи и Японии под ключ.

- `index.html` — выбор варианта
- `v1-keis.html` — «Кейс выдачи» (дорабатываемый)
- `v4-standart.html` — «Стандарт ниши»

Статичный HTML/CSS/JS без сборки. Страницы закрыты от поисковиков (`noindex`) — это демо; при запуске на основном домене убрать.
